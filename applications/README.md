## Runtime model

Each app follows a standard lifecycle:

- startup and state initialization
- config persistence
- service access
- permission checks
- shutdown cleanup

### Example app notes

- THREAD Files: browsing, metadata, copy, move, delete
- THREAD Settings: system configuration
- THREAD Terminal: shell sessions and command execution
- THREAD Monitor: CPU, RAM, storage, and process data
