# THREAD security

The security model is designed around real system principles and clear user controls.

## Security features

- user accounts and password authentication
- file ownership and permission checks
- process isolation
- firewall integration
- safe update and recovery paths
- explicit recovery prompts
- secure installer confirmation flows

## Principles

- do not invent fake protections
- show warnings clearly before dangerous actions
- use real Linux security semantics where practical
- keep audit and diagnostics transparent
