# THREAD hardware support

## Supported classes

- x86_64 Intel and AMD systems
- common SSD/HDD and NVMe devices
- USB keyboard and mouse devices
- Ethernet and Wi-Fi adapters
- Intel and AMD graphics where supported by upstream Linux drivers
- NVIDIA graphics where a driver is available and tested
- common audio devices
- touchpads and Bluetooth input devices where supported

## Unsupported or unverified hardware

Any hardware not validated must be presented explicitly as unsupported rather than silently assumed to work.
