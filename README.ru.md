## ✦ О THREAD

THREAD OS — проект операционной системы **Джамила Исламова**. Первая версия планируется на базе **ядра Linux** и **GRUB**, с собственным интерфейсом THREAD: рабочим столом, приложениями, инструментами рабочих сессий и установщиком.

> **Текущий статус:** это ранняя основа проекта, а не готовая ОС. Проверенного загрузочного установочного образа и протестированного рабочего стола пока нет. Для текущего ISO-скрипта нужны ядро и initramfs, которых в репозитории пока нет. Проверки загрузки в QEMU и на физическом оборудовании не проводились.

## ◈ Состояние проекта

**Этап: ранняя основа.** В репозитории есть документация, предварительная конфигурация GRUB, оформление и начальные скрипты. Это не означает, что образ ОС работает: скрипт сборки пока не создаёт полноценную live-систему, а загрузочной конфигурации ещё нужны настоящее ядро/initramfs и корректный механизм live-загрузки.

| Область | Статус |
|:--|:--|
| Архитектура x86_64 на базе Linux | Запланирована и описана |
| Загрузка GRUB BIOS + UEFI | Конфигурация начата; загрузка не проверялась |
| Ядро и initramfs | Не включены |
| Полная корневая файловая система live-системы | Не реализована |
| Рабочий стол THREAD и приложения | Запланированы; полноценный рабочий стол не реализован |
| Графический установщик и установка на диск | Не реализованы |
| Проверенный образ `THREAD.iso` | Пока недоступен |
| Проверка QEMU / физического оборудования | Не проводилась |

Пункты плана — это цели, а не утверждение, что функции уже работают. Статус будет обновляться по результатам реализации и тестирования.

## ⌘ Техническое направление

Первая цель — **x86_64**, ядро Linux и GRUB для Legacy BIOS и UEFI. Уникальность THREAD должна формироваться собственным рабочим столом, приложениями, настройками, восстановлением рабочих сессий, визуальной системой и инструментами установки — без ложных заявлений о независимом ядре.

Планируемые направления:

- **Загрузка:** GRUB, BIOS/UEFI, восстановление и безопасный графический режим.
- **Система:** драйверы Linux, обнаружение устройств, хранилище, сеть, учетные записи и журналы.
- **Рабочий стол:** тёмный интерфейс THREAD, панель, меню приложений, настройки и уведомления.
- **Приложения:** Files, Settings, Terminal, Browser, Store, Notes, Monitor, Network, Security, Update Center, Recovery и Workspace.
- **Установщик:** явный выбор диска, ручная/автоматическая разметка и подтверждение опасных действий.

Подробности: [архитектура](ARCHITECTURE.md) и [план разработки](ROADMAP.md).

## 🛠 Сборка и тестирование

Текущие скрипты — **начальные инструменты**, а не готовая система сборки ISO. Не используйте возможный результат для установки ОС или перезаписи USB. Интеграция ядра и файловой системы, live-загрузка, установщик и тесты загрузки ещё не готовы.

См. [BUILD.md](BUILD.md). Текущие точки запуска:

```bash
./scripts/build_iso.sh
./scripts/validate_iso.sh
./scripts/qemu_test.sh
```

Запуск этих команд **не доказывает**, что ОС загружается. Образ можно называть загрузочным только после сборки полной системы и проверки BIOS и UEFI в тестовой среде.

## 🧵 Принципы проекта

1. **Функциональность важнее декора:** макет не выдаётся за работающую ОС.
2. **Честность:** описываем только реализованное и проверенное.
3. **Контроль пользователя:** опасные операции требуют явного согласия.
4. **Поддерживаемая основа:** сначала компоненты Linux, затем возможная независимость ядра.
5. **Настраиваемость:** пользователь управляет внешним видом и поведением системы.
